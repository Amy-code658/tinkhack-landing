TinkHack 2025 Landing Page

This is the landing page for TinkHack 2025, a hackathon by TinkerHub MEC. It shows event info, registration, timeline, sponsors, and contact details.

Project Structure

tinkhack-landing/
│
├── index.html # Main webpage
├── style.css # Makes the page look nice with colors, fonts, and layout
├── script.js # Makes the menu work on mobile (click to open/close)
└── images/ # All images used on the page
├── logo.png
├── sponsor1.png
├── sponsor2.png
├── sponsor3.png
├── sponsor4.png
├── sponsor5.png
└── sponsor6.png

> `style.css` handles the design and responsiveness.  
> `script.js` handles the mobile menu toggle.

 Features

- Simple navigation bar with mobile menu toggle.  
- Sections for Overview, Timeline, Registration, Sponsors, and Contact.  
- Link to registration form.  
- Works on desktop and mobile.

How to Run

1. Download or clone this project.  
2. Make sure `index.html`, `style.css`, `script.js` and the `images/` folder are together.  
3. Open `index.html` in your web browser.

How to Customize

- Change images in the `images/` folder to update logo or sponsors.  
- Change `style.css` to adjust colors, fonts, or layout.  
- Update the registration form link in `index.html` if needed.
